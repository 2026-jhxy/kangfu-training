# 欢迎使用康复培训咨询网

本网站专注于康复与运动康复领域的培训资讯，为您提供最新、最全面的行业动态。

## 网站功能

### 📰 资讯浏览
- 浏览最新的康复培训动态
- 了解运动康复领域的专业课程
- 获取行业前沿资讯

### 🔍 内容分类
- 按类别浏览文章
- 按标签筛选内容
- 查看历史文章归档

## 如何开始

1. **浏览首页**：查看最新发布的资讯文章
2. **分类导航**：点击菜单中的「分类」，按主题浏览内容
3. **标签筛选**：点击「标签」，按关键词查找相关文章
4. **搜索功能**：使用搜索框快速定位感兴趣的内容
